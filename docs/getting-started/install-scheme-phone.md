# 手機安裝方案

在 iPhone 或 iPad 上直接下載並匯入蝦米方案（**不含皮膚**；皮膚請見 [手機安裝皮膚](../skin/install-on-phone.md)）。

> **升級用戶：** 若已安裝舊版方案，請先 [刪除舊方案](getting-started/remove-old-scheme.md) 再依下列步驟安裝。

## 步驟 1：複製方案網址

請先至 [選擇方案](getting-started/choose-scheme.md) 複製適合的下載網址。

## 步驟 2：匯入元書輸入法

### 2-1 開啟元書輸入法

![元書輸入法](../images/01-1元書icon.png)

### 2-2 選擇「輸入方案」

![輸入方案](../images/01-13輸入方案.png)

### 2-3 點擊「下載方案」

![下載方案](../images/01-14下載方案.png)

![下載方案 2](../images/01-15下載方案.png)

### 2-4 點擊「㊉」新增下載

![新增下載](../images/01-16㊉.png)

### 2-5 輸入名稱與網址

輸入「方案名稱（自訂）」、貼上「下載網址」並儲存。

![下載網址](../images/01-17下載網址.png)

### 2-6 下載並等待完成

點擊右方綠色按鍵下載，等待下載完成。

![下載完成 1](../images/01-18下載完成.png)

![下載完成 2](../images/01-19下載完成.png)

![下載完成 3](../images/01-20下載完成.png)

### 2-7 方案目錄切換

點擊「方案目錄切換」。

![下載方案](../images/01-14下載方案.png)

![方案目錄切換](../images/01-21方案目錄切換.png)

### 2-8 選擇 RimeUserData

依序選擇「RimeUserData」。

![RimeUserData](../images/01-22RimeUserData.png)

### 2-9 選擇方案名稱

選擇你自訂的「方案名稱」。

![方案名稱](../images/01-23方案名稱.png)

### 2-10 選擇 rime-liur-ios

選擇「rime-liur-ios」。

![rime-liur-ios](../images/01-24rime-liur-ios.png)

### 2-11 打開方案

點擊「打開」。

![打開](../images/01-25打開.png)

![清單](../images/01-26清單.png)
