# 啟用輸入法

安裝元書輸入法後，須在系統設定中啟用鍵盤。

### 步驟 1：開啟設定

開啟「設定」App。

![設定](../images/01-2設定icon.png)

### 步驟 2：進入鍵盤設定

選擇「一般」→「鍵盤」→「鍵盤」。

![一般](../images/01-3一般.png)

![鍵盤](../images/01-4鍵盤.png)

![鍵盤列表](../images/01-5鍵盤.png)

### 步驟 3：新增鍵盤

點擊「新增鍵盤」。

![新增鍵盤](../images/01-6新增鍵盤.png)

### 步驟 4：選擇元書輸入法

在第三方鍵盤中選擇「元書輸入法」。

![元書輸入法](../images/01-7元書輸入法.png)

### 步驟 5：允許完整取用

開啟「允許完整取用」。

![元書輸入法詳細](../images/01-8元書輸入法.png)

![允許完整取用](../images/01-9允許完整取用.png)

### 步驟 6：確認地球選單

若長按「地球」後，選單中沒有「元書輸入法」，請**重新開機**。

![地球選單](../images/01-10地球選單.png)

### 步驟 7：聽寫語言（建議）

選擇「一般」→「鍵盤」→「鍵盤」→「聽寫語言」。

![聽寫語言](../images/01-11聽寫語言.png)

### 步驟 8：取消國語－中國大陸

取消勾選「國語 - 中國大陸」。

![國語中國大陸](../images/01-12國語中國大陸.png)
