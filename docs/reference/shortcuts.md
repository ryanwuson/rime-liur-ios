# 快捷總表

| 功能 | 快捷鍵／引導鍵 | 說明 | 備註 |
|:-----|:---------------|:-----|:-----|
| 造詞模式 | `;` | 臨時造詞 | [造詞](/features/compose.md)；屏蔽無效鍵方案不適用 |
| 同音選字 | 左下角「同音」或 L 上滑 `'` | 打完字碼後使用 | [同音](/features/homophone.md) |
| 讀音查詢 | `;;` | 輸入字碼查讀音 | 需候選 Comment |
| 拼音鍵盤 | 工具列「拼」／iPad 左 Shift 下滑 | 切到獨立拼音方案 | [拼音](/features/pinyin.md)；下滑 QWERT 對應 1～5 聲調 |
| 快打模式 | `,,sp` | 提示可用簡碼 | [快打](/features/quick-mode.md)；需 Comment |
| 強制快打 | `,,sf` | 可續打簡碼出字 | [強制快打](/features/force-quick-mode.md)；需 Comment |
| 清除聯想記憶 | `,,clean`＋空白 | 清除個人學習資料 | [聯想字](/features/prediction.md#清除個人記憶)；固定聯想不受影響 |
| 計算機 | `,,=` | 四則運算 | [計算機](/features/calculator.md)；僅嘸蝦米方案；亦可用手勢 |
| 顏文字鍵盤 | 逗號 `,` 下滑 | 開啟顏文字面板 | [常用手勢](/daily-use/gestures-common.md) |
| Emoji 鍵盤 | 句號 `.` 下滑 | 開啟 Emoji 面板 | 同上 |
| 注音鍵盤 | iPhone Enter 上滑／工具列「ㄅ」／iPad 右 Shift 下滑 | 切到獨立注音方案 | [注音](/features/bopomofo.md) |
| 返回中文鍵盤 | iPhone 返回鍵上滑；iPad 返回鍵下滑 | 符號／數字等回蝦米鍵盤 | [工具列](/daily-use/toolbar.md) |
| 按鍵說明 | `,,h` | 顯示所有快捷鍵說明 | — |
