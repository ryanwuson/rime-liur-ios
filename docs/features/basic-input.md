# 基本輸入

## 蝦米字碼輸入

- 直接輸入蝦米字碼，按 `Space` 出字，或下滑 Q～P 鍵以 1～9 數字鍵選字
- 支援標準字碼、簡碼輸入
- 具備 VRSF 選字功能

## 中文及英文詞庫混合輸入

在完整版（中打含英文詞庫版）中，英文單詞會自動出現在候選選單中：

- **自動補全**：輸入 `app` 會在候選中顯示 `apple`、`application` 等
- **Shift + 字母（大寫）**：亦可帶出英文詞庫候選
- **空白鍵上屏**：選擇英文單詞後按 `Space` 即可上屏
- **大小寫轉換**：
  - 輸入英文單詞後上滑 C 鍵 1 次 → 首字母大寫（如：`word` → `Word`）
  - 輸入英文單詞後上滑 C 鍵 2 次 → 全部大寫（如：`word` → `WORD`）

## 英文輸入模式

`Shift` 上滑、點按 `Shift` 或工具列「英」可切換中英文鍵盤。兩種英文模式的**切換方式相同**，差別只在 [皮膚設計器](https://ggininder.work/r/Ryan) 的「英文鍵盤模式」設定（[設計器說明·佈局配置](https://ryanwuson.github.io/rime-liur-ios-new-skin/guide/#/settings/layout)）：

### 詞庫版（Easy English）

- **切換方式**：`Shift` 上滑、點按 `Shift` 或工具列「英」
- **皮膚設定**：英文鍵盤模式 → **詞庫版**
- **說明**：內建英文詞組，輸入完成按 `Space` 上屏；`Shift` + 字母（大寫）亦可帶出英文詞庫候選

### 純英文版

- **切換方式**：`Shift` 上滑、點按 `Shift` 或工具列「英」
- **皮膚設定**：英文鍵盤模式 → **純英文**
- **說明**：打字直出英文，不帶英文詞庫
