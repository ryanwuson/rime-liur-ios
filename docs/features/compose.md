# 造詞功能

## 臨時造詞

臨時造詞適合日常使用，造詞後可立即使用，系統會自動儲存。

### 操作方式

1. `上滑 K 鍵` 輸入 `;` 進入造詞模式（顯示《造詞》▸）
2. 依序輸入每個字的編碼，`上滑 A 鍵` 用 `` ` `` 分隔
3. 按空白鍵確認上屏

### 刪除臨時造詞

打出臨時造詞之編碼後，**下滑 Backspace** 即可刪除該詞條。

### 使用範例

- **造「臺北車站」**：``;te`ffl`cj`lzo`` → 臺北車站
- **造「行政院」**：``;mv`ezp`br`` → 行政院

### 編碼規則

造詞後會自動產生 4 碼快捷編碼，取每個字的「首碼」組合：

| 詞長 | 編碼規則 | 說明 |
|:----:|:--------:|:-----|
| 2 字詞 | ABBB | 第 1 字首碼 + 第 2 字首碼×3 |
| 3 字詞 | ABCC | 第 1 字首碼 + 第 2 字首碼 + 第 3 字首碼×2 |
| 4 字以上 | ABCZ | 第 1、2、3 字首碼 + 末字首碼 |

### 編碼範例

| 詞彙 | 各字首碼 | 造詞編碼 |
|:----:|:---------|:--------:|
| 台北 | 台(u) 北(f) | `ufff` |
| 行政院 | 行(m) 政(e) 院(b) | `mebb` |
| 台北市政府 | 台(u) 北(f) 市(l) 政(e) 府(l) | `ufll` |

### 注意事項

- 造詞後可立即使用，不需重新部署
- 關閉輸入法時會自動保存
- 「屏蔽無效鍵」方案不適用臨時造詞

## 直接編輯造詞

如需批量新增或與他人分享自訂詞庫，可直接編輯詞庫檔案。

### 操作步驟

1. 開啟「元書輸入法」→「文件管理」→「RimeUserData」→「方案文件夾」
2. 找到 `openxiami_CustomWord.dict.yaml`
3. 新增詞條（格式：`詞彙<Tab>編碼`），不受臨時造詞編碼規則限制
4. 儲存檔案並**重新部署**
5. 亦可透過 iMazing 等工具，將電腦端檔案放入對應資料夾
