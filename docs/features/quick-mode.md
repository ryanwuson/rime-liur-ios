# 快打模式

> 需開啟元書輸入法「候選 Comment」。設定見 [基本設定](/yuanshu-settings/basic-settings.md)。

## 功能說明

- **開關**：`,,sp`（輸入後按空格）
- **狀態**：正常 ↔ 快打
- **說明**：開啟後會提示可用的簡碼，幫助學習更快速輸入

## 功能特色

1. **簡碼提示**：當輸入的字有更短編碼時，會在候選旁顯示簡碼提示
2. **提升效率**：讓使用者學習並記住常用字簡碼
3. **即時顯示**：輸入時即時顯示可用簡碼選項

## 提示格式

- `簡碼▸⟨x⟩`：表示該字可用字碼 `x` 輸入
- 簡碼提示顯示在候選字註解區域

## 使用範例

| 輸入 | 候選字 | 簡碼提示 |
|:----:|:------:|:---------|
| `ttmb` | 頂 | ▸簡碼⟨TTA⟩ |
| `lonm` | 毫 | ▸簡碼⟨LVM⟩⟨LNM⟩ |

## 注意事項

- 快打模式主要用於學習簡碼；熟悉後可關閉以減少視覺干擾
- 簡碼提示依 **簡體／繁體** 模式不同
