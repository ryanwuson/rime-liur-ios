# 強制快打模式

> 需開啟元書輸入法「候選 Comment」。設定見 [基本設定](/yuanshu-settings/basic-settings.md)。

## 與快打模式的差異

| | 快打模式 | 強制快打 |
|---|----------|----------|
| 開關 | `,,sp` | `,,sf` |
| 行為 | 提示簡碼，供學習 | 上屏後若提示更短簡碼，**可直接續打簡碼出字**，無須清碼 |
| 範例 | 見提示後自行改打 | `ttmb` 空格上屏「頂」→ 見 `tta` → 直接打 `tta` 出「頂」 |

## 功能說明

- **開關**：`,,sf`（輸入後按空格）
- **狀態**：正常 ↔ 強制快打
- **說明**：行為更接近官蝦；打完字上屏後，候選區若提示更短簡碼，可續打簡碼出字

## 使用範例

| 輸入 | 候選字 | 簡碼提示 |
|:----:|:------:|:---------|
| `ttmb` | 頂 | ▸簡碼⟨TTA⟩ |
| `lonm` | 毫 | ▸簡碼⟨LVM⟩⟨LNM⟩ |

**續打範例**：`ttmb` → 空格上屏「頂」→ 見提示 `tta` → 直接輸入 `tta` 上屏「頂」

## 注意事項

- 熟悉簡碼後可關閉以減少干擾
- 簡碼提示依 **簡體／繁體** 模式不同
