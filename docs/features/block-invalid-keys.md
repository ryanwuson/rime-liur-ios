# 無效鍵屏蔽

帶有「屏蔽無效鍵」的方案，可根據當前輸入狀態動態屏蔽無效按鍵。

## 主要特色

1. **屏蔽功能**：根據當前輸入狀態屏蔽無效按鍵
2. **避免誤觸**：減少輸入錯誤，提升準確度

## 屏蔽邏輯

- **輸入進行中**：根據已輸入編碼，屏蔽不可能的後續按鍵
- **候選顯示**：有候選字時，保持數字鍵和空格鍵可用

## 視覺限制

方案中的「屏蔽無效鍵」**無法讓按鍵視覺變淡**──這是元書輸入法尚未支援的功能。按鍵仍顯示正常，但無效鍵不會響應。

![ab 後 c 仍顯示但無法按](../images/16-1屏蔽無效鍵視覺限制.gif)

## 適用場景

- **學習階段**：幫助初學者避免無效編碼
- **提升準確度**：減少誤觸
- **專注輸入**：專注於有效按鍵
