# 聯想字

## 功能特色

- 預設開啟聯想字功能，**簡體字也有相對應的聯想字**
- 可依上屏的第 1 個字進行聯想
- 1 次提供 24 個候選聯想字，自工具列下滑即可展開

![聯想字](../images/07聯想字.gif)

## 注意事項

- 因 Rime 候選字模組限制，無法判斷前後語意，屬於**「固定式」聯想**，不如部分內建輸入法的前後文聯想強大

### 若無需使用此功能

步驟見 [方案開關設定·關閉聯想字](getting-started/scheme-switches.md)。
