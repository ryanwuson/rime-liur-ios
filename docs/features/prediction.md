# 聯想字

本方案採用「**固定詞庫＋個人記憶**」的混合式聯想，預設開啟，繁體與簡體皆可使用。

![聯想字](../images/07聯想字.gif)

## 兩層聯想如何運作

| 層級 | 功能 |
|------|------|
| **固定式聯想** | 以內建 `predict.db` 為基礎，依剛上屏的字提供預先整理好的聯想候選 |
| **記憶式聯想** | 學習你實際輸入的前後配對；常用的下文會逐漸提前，固定詞庫沒有收錄的配對也能被記住 |

例如先後上屏「我」「國」，系統會記住「我 → 國」。之後打出「我」，「國」便可出現在聯想列；重複使用後，排序會逐漸提前。

記憶候選會與固定候選合併並去除重複，不會改動一般蝦米字碼的候選順序。

## 記憶與統計

每一組「上文 → 下文」會記錄：

- **使用次數**：相同配對每成功輸入一次，次數加一。
- **最後使用時間**：記錄最近一次使用的時間。
- **排序方式**：以使用次數為主，近期使用略為加分。因此長期常用的詞通常仍排在前面，剛使用一次的新詞不會立即取代高頻詞。

這些統計只用於聯想排序，沒有另外的統計畫面。資料保存在元書輸入法的 Rime 使用者目錄內，檔名為 `liu_user_predict.txt`。

## 什麼情況會學習

系統會在**連續兩次上屏純漢字**時學習配對：

- 每次上屏可為 1～4 個漢字。
- 前後兩次上屏需在 2 秒內完成。
- 疊字也可學習，例如「看 → 看」。

下列情況會中斷前後配對，不會把兩側內容記成聯想：

- 輸入標點、空格或換行。
- 輸入英文、數字或中英混合內容。
- 前後兩次上屏相隔超過 2 秒。
- 切換到英文輸入。

## 候選與連續聯想

- 每次最多顯示 24 個聯想候選。
- 同一個上文最多保留 15 組個人記憶；超出時保留最近使用的項目。
- 記憶式聯想最多可連續觸發 3 輪。
- 自工具列向下滑可展開更多候選。

## 清除個人記憶

在嘸蝦米鍵盤輸入：

```text
,,clean
```

再按**空白鍵**，即可清除全部個人聯想記憶。成功時會跳出通知「清除聯想字記憶」。

> 清除後會刪除 `liu_user_predict.txt` 並清空目前載入的記憶；內建的固定聯想 `predict.db` 不受影響，因此仍會看到原有的固定聯想字。

## 關閉聯想字

關閉聯想只會停止顯示聯想候選，**不等於清除已學習的記憶**。之後重新開啟時，原有個人記憶仍可繼續使用。

若不需要此功能，設定步驟見 [方案開關設定·關閉聯想字](/getting-started/scheme-switches.md)。

## 注意事項

這套功能依上屏內容學習配對，並不是能理解整句前後文的語意模型，因此與部分系統內建輸入法的語意聯想方式不同。
