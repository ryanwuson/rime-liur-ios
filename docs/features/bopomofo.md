# 注音輸入

## 注音輸入

- **引導鍵**：**Enter 上滑**或工具列「注音鍵盤」；首次切換會帶出 `';`
- **提示**：《注音輸入》▸
- **說明**：使用注音輸入中文，可連續輸入
- **舉例**：`';1upzpu,204j06w961o3` → 繽紛耶誕玩台北

詳見 [完整手勢：Enter 上滑](../daily-use/gestures-full.md#一般上滑及下滑)。

## 注音直出（注音文）

- **引導鍵**：`';'`；首次進注音鍵盤後，「直出」鍵上滑 1 次可帶出
- **提示**：《注音直出》▸
- **說明**：輸入注音符號；一聲請上滑「直出」鍵 1 次
- **舉例**：`';'wu3s/65''2u0''` → ㄊㄧˇㄋㄥˊㄓˉㄉㄧㄢˉ
