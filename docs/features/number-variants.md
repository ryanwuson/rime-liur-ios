# 變體英數

## 變體 Aa（首字母大寫）

- **引導鍵**：上滑 A + 上滑 J → `` `/ ``
- **提示**：《變體Aa》
- **說明**：用 `.` 分隔單字，單字首字母大寫
- **舉例**：`` `/hello.world `` → Ⓗⓔⓛⓛⓞ Ⓦⓞⓡⓛⓓ

## 變體 aa（全小寫）

- **引導鍵**：上滑 A + 上滑 J 兩次 → `` `// ``
- **舉例**：`` `//hello.world `` → ⓗⓔⓛⓛⓞ ⓦⓞⓡⓛⓓ

## 變體 AA（全大寫）

- **引導鍵**：上滑 A + 上滑 J 三次 → `` `/// ``
- **舉例**：`` `///hello.word `` → ⒽⒺⓁⓁⓄ ⓌⓄⓇⓁⒹ

## 變體數字－連打

- **引導鍵**：上滑 A + J + L → `` `/' ``
- **說明**：用 `.` 分隔數字；需數字鍵選字時，結尾按 `'`
- **舉例**：`` `/'123 `` → ①②③

## 變體數字－單選

- **引導鍵**：上滑 A + L → `` `' ``
- **範圍**：`` `'00 `` ～ `` `'50 ``
- **舉例**：`` `'01 `` → ① ⓵ ⑴ ⒈ …
