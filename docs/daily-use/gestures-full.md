## 點擊操作

- **字母鍵**：輸入蝦米編碼對應之字母
- **空格鍵**：選擇第 1 個候選字
- **候選字**：直接點選候選字上屏

![點擊操作](../images/03-3點擊操作.png)

<a id="長按操作"></a>

## 長按操作

### 字母鍵

中、英文鍵盤長按選單為**大、小寫英文直接輸出，變化形則在選單最後**（舊版預設為英文變化形）。

![長按字母](../images/03-3-2長按操作字母.gif)

### 123 鍵

顯示數學符號選單（+、-、×、÷、=、≠）。

![長按 123](../images/03-3-4長按操作123.gif)

### 「,」及「.」鍵

開啟「日期時間」選單。

![長按標點](../images/03-3-5長按操作，。.gif)

<a id="shift-鍵"></a>

### Shift 鍵

- **上滑**：切換中文及英文鍵盤
- **下滑**：切換至下一個輸入法（解決 SE 機型無地球問題）

![Shift 上滑](../images/03-11-4Shift鍵上滑.gif)

![Shift 下滑](../images/03-11-4Shift鍵下滑.gif)
---

<a id="enter-鍵"></a>

### Enter 鍵

- **上滑** → 注音鍵盤：
  - 首次切換會帶入引導鍵 `';`，所打文字已上屏；要再以注音輸入請按「**輸入**」鍵（空白鍵右邊）
  - 輸入**注音文**請按「**直出**」鍵（空白鍵左邊），帶入 `';＇`；注音一聲為「**直出**」鍵上滑
  - 若首次進注音但要輸入注音文，可上滑「**直出**」鍵，引導鍵變更為 `';'`
- **下滑**：換行；部分 App 無換行功能，下滑 Enter 可強制換行

![Enter 上滑](../images/03-11-5「Enter」鍵上滑.gif)

![Enter 下滑](../images/03-11-5「Enter」鍵下滑.gif)

<a id="特殊上滑及下滑"></a>

## 特殊上滑及下滑

![特殊上下滑](../images/03-11特殊上下滑.png)

| 手勢 | 功能 |
|------|------|
| **A 上滑** `` ` `` | 字母變體、數字變體 |
| **C 上滑** `]` | 英文字首大寫 |
| **C 上滑 2 次** `]]` | 英文全大寫 |
| **K 上滑** `;` | 臨時造詞（屏蔽無效鍵方案不適用） |
| **K 上滑 2 次** `;;` | 讀音查詢（需候選 Comment） |
| **K、L 依序上滑** `;'` | 拼音輸入 |
| **L 上滑** `'` | 同音字 |
| **Z～M 下滑** | Z 句首／X 剪／C 複／V 貼／B Tab／N 全選／M 句尾 |
| **Z、N、M 上滑** | Z 單手模式／N 第 2 候選／M 第 3 候選 |

<a id="backspace-滑動"></a>

## Backspace 滑動

![Delete 上下滑](../images/03-11Delete上下滑.png)

| 情境 | 手勢 | 效果 |
|------|------|------|
| 輸入字碼後 | **左滑** | 清除所有字碼 |
| 臨時造詞字碼 | **下滑** | 清除臨時造詞 |
| 已上屏文字 | **上滑** | 清除所有上屏文字 |
| 清除上屏後 | **下滑** | 回復前次清除之上屏文字 |
| N 下滑全選後 | **下滑** | 取消全選 |
| 已上屏文字 | **長按 + 左滑** | 逐字刪除已上屏文字 |
| 長按不放，再 **右滑** | （接續上項，勿放開長按） | 逐字回復剛刪除的文字 |
