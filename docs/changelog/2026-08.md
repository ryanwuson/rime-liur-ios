# 2026-08 版本更新說明

## 方案部分

1. **獨立注音／拼音鍵盤**  
   切到「注音鍵盤」「拼音鍵盤」即進入獨立方案，直接打注音或拼音。注音鍵盤內 **Enter 上滑** 可上屏注音文；拼音鍵盤內 **Enter 上滑** 為帶音標。組字中「返回」會變成 **分節**。支援首碼（如 `ㄅ ㄓ ㄉ` →「不知道」、`p g` →「蘋果」）、無聲調輸入、記住打過的詞組；單字候選會附上蝦米字碼，方便學習拆碼。詳見 [注音輸入](/features/bopomofo.md)、[拼音輸入](/features/pinyin.md)。

2. **注音／拼音隨附 Emoji**  
   以注音或拼音鍵盤輸入時，候選隨附對應 Emoji。詳見 [隨附 Emoji](/features/emoji.md)。

3. **同音補漏**  
   補足同音字缺漏；例如打「康」後選同音可找到「鱇」等字。詳見 [同音選字](/features/homophone.md)。

4. **讀音依據**  
   繁體依教育部《重編國語辭典修訂本》並參考《異體字字典》；簡體依《新華字典》。影響 `;;` 讀音查詢與注音鍵盤顯示的讀音。詳見 [注音輸入·讀音依據](/features/bopomofo.md#讀音依據)。

5. **混合式聯想**  
   固定詞庫 `predict.db` 加上個人記憶與統計（次數、最近使用）；`,,clean`＋空白可清除個人記憶，並跳出「清除聯想字記憶」。每次最多顯示 24 個聯想候選。詳見 [聯想字](/features/prediction.md)。

## 皮膚部分

1. **iPad 切換注音／拼音**  
   主鍵盤 **左 Shift 下滑** 進拼音、**右 Shift 下滑** 進注音（鍵面有標示）。iPhone 仍可用 **Enter 上滑** 進注音。詳見 [鍵盤佈局](/daily-use/keyboard-layout.md)。
